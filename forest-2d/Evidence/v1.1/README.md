# Menu and demonstration update

2026-11-12, Asia/Hong_Kong. UE 5.8.1, Win64 Development.

- Added clickable Play, Watch demo and Quit game buttons on the start menu. Quit is also available from pause, help and completion; Resume is clickable while paused.
- Menu cursor and input mode switch with menu state. Q exits from a menu; V begins the demonstration. Escape interrupts the demonstration so players can take control. A completed demonstration releases control back to the normal completion menu.
- The packaged `-ForestQuitSmoke -ForestCapture` check located the actual rendered Quit hitbox, dispatched a click through UE's HUD hitbox dispatcher, logged `FOREST_MENU_QUIT requested`, and exited through `UGameEngine::HandleExitCommand` with status 0. See `quit-smoke.json` and `start-menu.png`.
- An additional real Q key input sent to the foreground packaged-game window also logged the quit request and exited with status 0; the window disappeared.
- All three existing UE gameplay regression suites passed again. See `automation-report.json`.
- A real V key input on the packaged game's start menu launched the demonstration. It completed all 75 input steps and reached order stage 9 with zero teleports. See `menu-demo-replay.json`. The demonstration was shown in a visible game window.

The hitbox smoke test injects the click into UE and does not claim physical mouse-device testing. Native window image capture was unavailable; the screenshot is generated by UE and was visually reviewed.
